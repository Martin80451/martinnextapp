## Getting Started

First, run the development server:

```bash
npm run dev # For starting the development server using Turbopack.
```

Other helpful commands:

```bash
npm run build # For building the application for production.
# or
npm run lint # For running the ESLint scan.
# or
npm run start # For starting the production server
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
